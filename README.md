# Enterprise Infrastructure Engineering

A practical infrastructure engineering portfolio covering Linux administration, databases, networking, automation, troubleshooting, and infrastructure architecture.

This repository focuses on practical implementation and operational thinking rather than theory alone.

## Core Areas

- Enterprise Linux
- PostgreSQL
- MongoDB
- Networking
- Storage & LVM
- Backup & Recovery
- High Availability
- Monitoring & Troubleshooting
- Bash
- Python
- Ansible
- Terraform

| Directory | Purpose |

## Approach

The repository is organized around four practical areas:

Knowledge → Architecture → Automation → Operations & Troubleshooting

The objective is to demonstrate the ability to understand infrastructure, design solutions, automate repetitive work, and troubleshoot production-style problems.

## Disclaimer

Examples and runbooks are intentionally generic and sanitized. No confidential organizational, customer, credential, or production-specific information is included.
